# Restaurant Cafe en Padel City

Wireframe funcional de baja fidelidad para "Restaurant Cafe en Padel City" - Una aplicación web moderna que combina información del restaurante, consejos nutricionales y contenido interactivo.

## 📋 Descripción

Este proyecto es un wireframe funcional desarrollado con React y Tailwind CSS que presenta tres pantallas principales:

1. **Inicio** - Hero section con tarjetas de platillos destacados
2. **Tips** - Artículos detallados sobre nutrición y alimentación saludable
3. **Interactivo** - Quiz de personalidad para descubrir preferencias culinarias
4. **Contacto** - Información de contacto y formulario

## 🚀 Instalación y Uso

### Prerequisitos

- Node.js (versión 16 o superior)
- npm o yarn

### Pasos de Instalación

1. Clona este repositorio:
```bash
git clone https://github.com/tu-usuario/restaurant-cafe-padel-city.git
cd restaurant-cafe-padel-city
```

2. Instala las dependencias:
```bash
npm install
# o
yarn install
```

3. Inicia el servidor de desarrollo:
```bash
npm run dev
# o
yarn dev
```

4. Abre tu navegador en `http://localhost:5173`
